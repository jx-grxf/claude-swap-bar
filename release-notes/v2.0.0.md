## Highlights

- **Accounts side by side instead of swapping.** Each Claude Code account now lives in its own configuration folder (`CLAUDE_CONFIG_DIR`), logs in once and stays logged in. Work and private accounts can run in two terminals at the same time.
- **New `cseat` command.** `cseat work` starts Claude Code with the work account, `cseat use work` makes it the default for plain `claude`, and `cseat` lists every account with its usage.
- **Shared setup.** Every account shares settings, skills, plugins, hooks, memory and transcripts with your normal `~/.claude`. User MCP servers and project trust follow along.
- **Remote Control and claude.ai connectors work in every account**, because each one uses a normal claude.ai login.

## Fixes

- No more random logouts from switching. Version 1 swapped one shared login and kept copies of single-use refresh tokens, which went stale. Version 2 never writes, refreshes or copies a login.
- Accounts whose token expired show as idle instead of being refreshed in the background.

## Upgrading from 1.x

- Your normal `~/.claude` login becomes the `main` account. Add other accounts again with **＋** or `cseat add <name>`; the 1.x account list isn't imported.
- Click **Install** in the popover once to set up `cseat` and the `claude` shell integration.
